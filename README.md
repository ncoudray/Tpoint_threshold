# Tpoint_threshold

This repository contains Matlab code of the T-point threshold used to threshold highly noisy images showing a unimodal histogram. 

If you find this work useful, please cite:
Coudray, N., Buessler, J.L. and Urban, J.P., 2010. Robust threshold estimation for images with unimodal histograms. Pattern Recognition Letters, 31(9), pp.1010-1019.
